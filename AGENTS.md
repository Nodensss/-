# AGENTS.md

Инструкции для ИИ-агентов (Codex и других), которые работают с этим репозиторием.

## Проект

Tank App — калькулятор перекачки и расхода раствора перекиси для связок ёмкостей 321 → 323 и 315 → 324: на сколько хватит раствора и во сколько он закончится. React 19 + Vite + TypeScript, Tailwind через CDN. Приложение создано в Google AI Studio.

Техническое задание: [docs/TZ_CODEX.md](docs/TZ_CODEX.md). Прочитай его целиком перед началом работы и делай только тот этап, который попросили.

## Команды

- `npm ci` — установка зависимостей
- `npx tsc --noEmit` — проверка типов
- `npm test` — тесты (появятся на этапе 1 ТЗ)
- `npm run build` — сборка

Перед сдачей всё должно проходить без ошибок.

## Правила

- Интерфейс, документация и комментарии — на русском, идентификаторы — на английском.
- Формулы и константы ёмкостей — только в `core/`. Компоненты только показывают результат.
- `core/` и `sim/` — чистые функции: без React, без DOM, без `new Date()` внутри (время передаётся параметром).
- Не переносить и не переименовывать `index.html`, `index.tsx`, `App.tsx`, `vite.config.ts`. Importmap и CDN в `index.html` не трогать.
- Новых runtime-зависимостей не добавлять. devDependencies — только для тестов.
- Коэффициенты пересчёта (38/382 и 1,2814) и уровни (30 %, 350 мм, 160 и 260 мм, 634 мм) получены по факту — не менять.
- Неизвестное о реальной установке не выдумывать: оформлять параметром с пометкой `УТОЧНИТЬ`.
- Репозиторий публичный: никаких ФИО, табельных номеров, телефонов, названия предприятия, реальных тегов и снимков экранов АСУ ТП.
- Расчёт — подсказка оператору, а не управление процессом. В интерфейсе и документах не должно быть ничего похожего на команду оборудованию.
